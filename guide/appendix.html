A1. Monday-Morning Launch Checklist (HRP v2.0)

Use this checklist to move from strategy to execution immediately.

Technical Infrastructure (Ingestion Layer)

  • HTTPS enabled across all pages
  • Mobile performance score acceptable (Core Web Vitals)
  • Clean HTML (no hidden or cloaked text)
  • Text-to-HTML ratio above 15%
  • CSS and JavaScript minified

AI Bot Access

  • GPTBot allowed in robots.txt
  • Google-Extended allowed
  • ClaudeBot allowed
  • No blanket AI bot blocking rules

Schema Implementation

  • Organization schema live
  • FAQPage schema added to priority pages
  • Author (Person) schema implemented
  • Speakable schema applied where relevant

Content Structure

  • First 100 words answer the core question
  • H1 and H2 use Subject → Predicate → Object
  • TL;DR block added to key pages
  • Tables used for comparisons and pricing

Trust Signals

  • Author bios linked and complete
  • Case study with metrics published
  • Third-party profiles updated and consistent

If every box above is checked, your brand is AI-eligible.

A4. Organization Schema (JSON-LD Template)

Use this as a base and customize for your brand. This connects your brand to trusted knowledge graph nodes.

{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Your Brand Name",
  "url": "https://www.yoursite.com",
  "logo": "https://www.yoursite.com/logo.png",
  "sameAs": [
    "https://www.linkedin.com/company/yourbrand",
    "https://twitter.com/yourbrand",
    "https://www.crunchbase.com/organization/yourbrand"
  ]
}

A5. FAQPage Schema (AI Answer Accelerator)

Use FAQ schema to increase direct answer eligibility. Keep answers Short, Direct, and Non-promotional.

{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "What is Generative Engine Optimization (GEO)?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "Generative Engine Optimization is the process of structuring content so it can be retrieved, cited, and used by AI answer engines like ChatGPT and Gemini."
    }
  }]
}

A6. Author Bio Page Template (E-E-A-T Critical)

Every author must have a dedicated page. This converts content into expert-authored knowledge.

Required Sections

  • • Full name
  • • Role and expertise
  • • Years of experience
  • • Credentials or certifications
  • • Real photo (not stock)
  • • SameAs links (LinkedIn, Twitter)

Example Structure

Name: Jane Smith

Role: AI Visibility Strategist

Experience: 12+ years in SEO

Specialty: GEO, Schema Architecture

As seen in: Industry blogs, podcasts
